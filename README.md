# Claude Code на Android — с управлением телефоном

Установка [Claude Code](https://claude.com/claude-code) (ИИ-ассистент Anthropic для терминала) прямо на Android-телефон
**без root и без компьютера**. Claude сможет не только писать код, но и **управлять телефоном**: нажимать на экран,
вводить текст, открывать приложения, делать скриншоты, устанавливать APK и работать в приложениях на
**скрытом виртуальном экране**, не мешая вам.

Установка — **одна команда**, запуск — **одна кнопка** на рабочем столе.

```
Телефон
├── Termux              — терминал (Linux в Android)
│   ├── мост rish ──────────► Shizuku ──► Android (тапы, скриншоты, приложения — права как у adb)
│   └── Ubuntu (proot)
│        └── Claude Code  (команды rish, shot, tap-text, vdisplay, vshot)
├── Termux:Widget       — кнопки «Claude» и «Claude-Stop» на рабочем столе
└── Termux:Boot         — автозапуск после перезагрузки
```

---

## Что понадобится

- Android-телефон **Android 11 или новее**, 64-битный (почти все телефоны после 2019 г.).
- **3 ГБ** свободной памяти и Wi-Fi (для первичной настройки Shizuku телефон должен быть подключён к Wi-Fi).
- Аккаунт Claude с подпиской **Pro или Max** (или аккаунт Anthropic Console с оплатой API).
- 20–30 минут.

> Root не нужен. Компьютер не нужен.

---

## Шаг 1. Установите 4 приложения

Скачивайте APK-файлы **с GitHub** по ссылкам ниже (открывайте ссылки в браузере на телефоне).
На странице релиза пролистайте до раздела **Assets** и нажмите на нужный файл.

| Приложение | Ссылка | Какой файл скачать |
|---|---|---|
| **Termux** | [github.com/termux/termux-app/releases/latest](https://github.com/termux/termux-app/releases/latest) | `termux-app_…_arm64-v8a.apk` |
| **Termux:Widget** | [github.com/termux/termux-widget/releases/latest](https://github.com/termux/termux-widget/releases/latest) | `termux-widget-app_…apk` |
| **Termux:Boot** | [github.com/termux/termux-boot/releases/latest](https://github.com/termux/termux-boot/releases/latest) | `termux-boot-app_…apk` |
| **Shizuku** | [Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) или [GitHub](https://github.com/RikkaApps/Shizuku/releases/latest) | `shizuku-…-release.apk` |

Когда откроете скачанный APK, Android скажет, что установка из неизвестных источников запрещена —
нажмите **«Настройки» → включите «Разрешить из этого источника»** → вернитесь назад → **«Установить»**.

> ⚠️ **Не ставьте Termux из Google Play** — там старая неработающая версия. Termux, Termux:Widget и Termux:Boot
> должны быть **из одного источника** (все с GitHub), иначе они не увидят друг друга.
> Если Termux уже стоит из Play Маркета — удалите его и поставьте с GitHub.

После установки **откройте один раз Termux:Boot** (просто запустите и закройте) — иначе автозапуск не заработает.

## Шаг 2. Включите «Режим разработчика»

1. **Настройки → О телефоне** (на Samsung: **Настройки → Сведения о телефоне → Сведения о ПО**).
2. Найдите строку **«Номер сборки»** и **нажмите на неё 7 раз подряд**. Введите PIN-код, если попросит.
   Появится надпись «Вы стали разработчиком».
3. Вернитесь в **Настройки** — появился пункт **«Параметры разработчика»** (обычно в самом низу или в «Система»).

---

## Шаг 3. Запустите Shizuku

Shizuku даёт Claude права для управления телефоном (такие же, как у компьютера, подключённого по кабелю через ADB).

1. Подключите телефон к **Wi-Fi**.
2. Откройте **Shizuku**. В блоке **«Запуск через беспроводную отладку»** нажмите **«Сопряжение»** (Pairing).
   Shizuku попросит разрешить уведомления — разрешите.
3. Нажмите **«Параметры разработчика»** (кнопка в Shizuku) или откройте их сами →
   включите **«Отладка по Wi-Fi»** (Wireless debugging) → **«Разрешить»**.
4. Нажмите на текст **«Отладка по Wi-Fi»** (зайдите внутрь) → **«Подключить устройство с помощью кода»**.
   Появится **6-значный код**.
5. Не закрывая окно с кодом, **опустите шторку уведомлений** — там уведомление Shizuku с полем ввода.
   Нажмите **«Ввести код»**, введите 6 цифр, отправьте. Должно появиться «Сопряжение выполнено».
6. Вернитесь в **Shizuku** → нажмите **«Запустить»** (Start). Через несколько секунд вверху будет
   **«Shizuku запущен»**.

> Сопряжение делается **один раз**. После перезагрузки телефона нужно только открыть Shizuku и нажать
> **«Запустить»** (Wi-Fi должен быть включён). В новых версиях Shizuku в настройках есть
> **«Запускать при загрузке (беспроводная отладка)»** — включите, и это будет происходить само.

## Шаг 4. Установка — одна команда

1. Откройте **Termux**. Дождитесь, пока появится строка с `$`.
2. Скопируйте эту команду (долгое нажатие → «Копировать»):

   ```bash
   curl -fsSL https://raw.githubusercontent.com/z1nmk/claude-code-android/main/install.sh | bash
   ```

3. В Termux: **долгое нажатие на экран → «Paste»** (Вставить) → нажмите **Enter** на клавиатуре.

Дальше всё произойдёт само (**10–20 минут**, зависит от интернета). По ходу установки:

- Android спросит **доступ к файлам** → **«Разрешить»**.
- Shizuku спросит **«Разрешить Termux доступ к Shizuku?»** → **«Разрешать всегда»**.
- Если терминал спросит что-то вроде `Y/n` — нажмите **Enter**.

В конце появится **«Установка завершена!»**. Не закрывайте Termux, пока установка идёт.

<details>
<summary>Что именно делает установщик</summary>

1. Обновляет Termux и ставит пакеты `proot-distro socat tmux unzip curl`.
2. Достаёт `rish` (консоль Shizuku) из установленного приложения Shizuku.
3. Кладёт скрипты: `~/claude-start.sh`, `~/claude-stop.sh`, `~/rish-bridge.sh`, `~/phone-setup.sh`, `~/doctor.sh`,
   автозапуск `~/.termux/boot/claude`, кнопки `~/.shortcuts/Claude` и `~/.shortcuts/tasks/Claude-Stop`.
4. Ставит Ubuntu (`proot-distro install ubuntu`), обновляет её (`apt-get update && apt-get upgrade`) и ставит программы
   `socat curl wget git gh jq python3 unzip ffmpeg nano`, затем — Claude Code (официальный установщик `claude.ai/install.sh`),
   команды `rish`, `shot`, `tap-text`, `vdisplay`, `vshot` в `/usr/local/bin`, настройки `~/.claude/settings.json`
   (разрешение на `rish` без лишних вопросов) и `~/.claude/CLAUDE.md` с инструкцией для Claude, как управлять телефоном.
5. Через Shizuku снимает фоновые ограничения Android, чтобы система не убивала Claude
   (phantom process killer, оптимизация батареи, экономия трафика), и готовит скрытый виртуальный экран (scrcpy-server).

Повторный запуск команды безопасен — он обновляет скрипты до последней версии.
</details>

## Шаг 5. Кнопка на рабочем столе

1. Долгое нажатие на пустое место рабочего стола → **«Виджеты»**.
2. Найдите **Termux:Widget** → перетащите виджет на рабочий стол.
3. На виджете будут кнопки: **Claude** (запустить) и **Claude-Stop** (остановить).

Также дайте Termux разрешение **«Поверх других приложений»**
(Настройки → Приложения → Termux → «Появление поверх других приложений» → включить) —
без него кнопка виджета на новых Android может не открывать окно.

---

## Шаг 6. Первый запуск и вход

1. Нажмите кнопку **Claude** на виджете. Откроется Termux с Claude Code.
2. Выберите тему (Enter), затем способ входа — **Claude account with subscription**.
3. Откроется браузер — войдите в свой аккаунт Claude и нажмите **«Authorize»**.
   Если браузер не открылся — нажмите на ссылку в терминале или скопируйте её в браузер вручную.
   Если просят вставить код — скопируйте его со страницы и вставьте в Termux (долгое нажатие → Paste).
4. На вопрос «Do you trust the files in this folder?» ответьте **Yes**.

Готово! Пишите Claude по-русски, например:

- «Сделай скриншот экрана и скажи, что на нём»
- «Открой YouTube и найди видео про котиков»
- «Запусти Chrome на скрытом экране, открой погоду в Москве и пришли скриншот»
- «Сколько свободной памяти и какой заряд батареи?»
- «Установи APK из папки Загрузки»

**Управление с другого устройства.** Claude запускается в режиме удалённого управления (`claude --remote-control`):
эта сессия появляется в приложении Claude и на [claude.ai/code](https://claude.ai/code) — можно давать команды
телефону с компьютера или другого телефона.

### Как это работает дальше

- **Свернуть Claude:** просто выйдите из Termux кнопкой «Домой» — Claude продолжит работать в фоне.
  Вернуться — снова кнопка **Claude**.
- **Остановить всё:** кнопка **Claude-Stop**.
- **После перезагрузки** телефона Claude запустится сам (Termux:Boot). Нужно только, чтобы был запущен Shizuku (см. шаг 3).

## Проверка и решение проблем

В Termux выполните:

```bash
~/doctor.sh
```

Скрипт проверит каждую часть и подскажет, что исправить.

| Проблема | Решение |
|---|---|
| Claude говорит, что `rish` ничего не возвращает | Shizuku остановлен (обычно после перезагрузки). Откройте Shizuku → «Запустить». |
| «Shizuku не отвечает» при установке | Запустите Shizuku (шаг 3), затем в Termux: `~/phone-setup.sh` |
| Кнопка «Claude» на виджете ничего не делает | Дайте Termux разрешение «Поверх других приложений» (шаг 5). |
| Claude «засыпает» / Termux закрывается в фоне | Настройки → Приложения → Termux → Батарея → **«Без ограничений»**. То же для Shizuku. На Samsung также уберите Termux из «Спящих приложений». |
| `Repository … not found` / ошибки `pkg` | В Termux: `termux-change-repo` → выберите любое зеркало → повторите команду установки. |
| Нужно переустановить / обновить | Просто снова выполните команду установки из шага 4. |
| Автозапуск после перезагрузки не работает | Откройте один раз приложение Termux:Boot. Termux и Termux:Boot должны быть с GitHub. |

Посмотреть окно Claude вручную: `tmux attach -t claude` (выйти, не останавливая: `Ctrl+B`, затем `D`).

## Команды, которые получает Claude

| Команда | Что делает |
|---|---|
| `rish -c '…'` | любая команда Android с правами ADB: `input tap X Y`, `input text`, `am start`, `pm install`, `settings`, `dumpsys`… |
| `shot out.png` | скриншот экрана |
| `tap-text "Текст"` | нажать на кнопку/элемент с таким текстом |
| `vdisplay start` / `stop` / `status` | скрытый виртуальный экран, где Claude работает с приложениями, не мешая вам |
| `vshot out.png` | скриншот скрытого экрана |

Инструкция для Claude лежит в `~/.claude/CLAUDE.md` (внутри Ubuntu) — её можно дополнять своими правилами.

## Безопасность — прочитайте

- Claude получает **права уровня ADB**: может нажимать что угодно, открывать любые приложения, читать экран,
  устанавливать и удалять приложения. Команды `rish` разрешены **без подтверждения** (настройка в
  `~/.claude/settings.json`). Если хотите подтверждать каждую команду — удалите оттуда строку `"Bash(rish:*)"`.
- Мост `rish` слушает только `127.0.0.1` (доступен только на самом телефоне), но любое приложение на телефоне
  теоретически может к нему подключиться, пока он запущен. Останавливайте всё кнопкой **Claude-Stop**, когда не пользуетесь.
- Не давайте Claude задач с покупками, банковскими приложениями и отправкой сообщений без вашего контроля.

## Удаление

```bash
sh ~/claude-code-android/uninstall.sh        # убрать скрипты, кнопки и автозапуск
sh ~/claude-code-android/uninstall.sh --all  # то же + удалить Ubuntu с Claude Code
```

Затем можно удалить приложения Termux, Termux:Widget, Termux:Boot и Shizuku, а в «Параметрах разработчика» выключить
«Отладку по Wi-Fi».
